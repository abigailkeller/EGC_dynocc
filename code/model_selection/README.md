Model selection

`model1.R`: 
- colonization: function of CPUE and C, separate coefficients for t-1 and t-2
- persistence: function of CPUE and C at t-1

`model2.R`: 
- colonization: function of CPUE and C, one coefficient for t-1 and t-2
- persistence: function of CPUE and C at t-1

`model3.R`: 
- colonization: function of CPUE and C, only t-1
- persistence: function of CPUE and C at t-1 

`model4.R`: 
- colonization: function of C, only t-1
- persistence: function of CPUE and C at t-1 

`model5.R`: 
- colonization: function of C, only t-1
- persistence: function of C at t-1 

`model6.R`: 
- colonization: intercept-only
- persistence: function of CPUE and C at t-1 

`model7.R`: 
- colonization: intercept-only
- persistence: function of C at t-1 

`model8.R`: 
- colonization: intercept-only
- persistence: intercept-only
